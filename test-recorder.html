ÆtherStrum 录音链路测试 Recorder pipeline tests

如何运行 / How to run
本页会通过 fetch('index.html') 提取 index.html 中 <script id="aether-wav-core"> 的真实录音核心代码并直接测试它。 由于浏览器通常禁止 file:// 页面读取本地文件，请在仓库目录启动一个本地服务器：
python -m http.server 8000（或 npx serve）
然后打开 http://localhost:8000/test-recorder.html。 Firefox 直接双击打开本文件通常也可以。
