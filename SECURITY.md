# Security

Bone 2D runs entirely in your browser: there is no server and no account, and files you open are not uploaded anywhere. What can go wrong is therefore mostly about what the editor does with a file it is given: a project (`.bone2d`), a Spine file, a Photoshop file, a review page or an export settings file.

If you find a way to make the editor run a script from a file, read something outside the file you opened, or send data somewhere without your action, please report it privately:

- use **Security → Report a vulnerability** on the [repository page](https://github.com/iamgatz/Bone-2D/security/advisories/new), or
- open an issue that says only "security report" and no details; the maintainer will reply with a private way to send them.

Please give the version (shown in the Updates window), the browser, and a file or steps that reproduce it. A first reply usually comes within a week. Fixes go into the next release and the report is credited, if you like, in its notes.

Only the latest release on [the site](https://iamgatz.github.io/Bone-2D/) is supported.
