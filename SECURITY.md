# Security Policy

## Supported version

Security fixes are considered for the current `main` branch of this repository.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use the repository’s [private security advisory form](https://github.com/vincenzo-afk/MARIO/security/advisories/new) when available, or contact the repository owner through the [vincenzo-afk GitHub profile](https://github.com/vincenzo-afk).

Include a clear description, reproduction steps, affected browser or device details, and any proof-of-concept information needed to assess the report. Do not include secrets, access tokens, or personal data. The project does not publish a guaranteed response-time commitment.

## Scope

Report issues that could affect the security or privacy of players, contributors, or the project’s build and deployment process. Ordinary gameplay defects, visual bugs, and feature suggestions should use the repository’s public issue forms.
