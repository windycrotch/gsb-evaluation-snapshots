## Overview

**StageFlow v1.1.2** is a focused visual ergonomics and optical LOD patch on top of `v1.1.1`. It resolves inconsistent 3D billboard badge sizing across desktop camera distances and prevents badges from appearing oversized on mobile and narrow split-pane viewports, while keeping all label and sublabel text intact.

---

## What's Fixed in v1.1.2

### 🏷️ Responsive & FOV-Normalized 3D Billboard Label Sizing ([#16](https://github.com/taruma/stageflow/issues/16))
- **Tighter Perspective Scale Bounds (`src/stage/labelLodMath.ts`)**: Tightened `MAX_PERSPECTIVE_SCALE` from `1.55` to `1.08` and raised `MIN_PERSPECTIVE_SCALE` from `0.72` to `0.75` to eliminate close-range badge bloat on desktop and mobile while retaining subtle depth cueing.
- **Horizontal-FOV Distance Normalization (`computeEffectiveLodDistanceM`)**: Normalized LOD scaling and pill-to-dot collapse distances against horizontal angular coverage (`aspectRatio * tan(fovY / 2)`) anchored to StageFlow's `35mm` full-frame baseline (`REF_HALF_HORIZ_TAN`), keeping telephoto (`85mm`) pills readable beyond `28m`, collapsing wide-angle (`24mm`) clutter earlier, and keeping adaptive narrow-pane FOV widening (`computeAdaptiveDioramaFovDeg`) LOD-invariant—while preserving physical proximity culling (`< 1.2m`) on raw Euclidean distance.
- **Unified-Breakpoint CSS Sizing & Zero-Churn 60fps Sync (`src/stage/StageBillboardLabel.tsx`)**: Aligned `getBillboardSizeTier()` (`COMPACT_CANVAS_WIDTH_PX = 768`) with `isNarrowDiorama` (`CompactDioramaHeader`) so React re-renders only when crossing `768px`, switching cleanly between `standard` (`px-3 py-1`, `13px`/`11px`) and `compact` (`px-2 py-0.5`, `11px`/`10px`) pill typography while passing live `PerspectiveCamera.fov` and canvas aspect ratio inside `useLayoutEffect` and `useFrame`.
