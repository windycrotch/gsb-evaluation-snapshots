首个公开发布版本：独立延迟 Chrome 标签页的声音，或同时延迟播放器画面与声音。

- 纯音频及音画一起延迟，支持 0～60 秒设置和 ±0.5 秒微调。
- 自动识别播放器、手动框选及整个标签页三种采集范围。
- 720p/30、720p/60、1080p/30、1080p/60 四档目标画质，支持独立播放页和全屏。
- 音视频在本地处理，无账号、服务器或遥测。
- GitHub Actions 自动生成固定密钥签名的 CRX3、ZIP 和 SHA-256 校验文件。

### 下载与安装

普通 Chrome 用户建议下载 **BilibiliLiveDelay-v1.3.0.zip**，解压后在 `chrome://extensions` 开启「开发者模式」，点击「加载已解压的扩展程序」，选择含 `manifest.json` 的文件夹。需要 Chrome 116+。

**BilibiliLiveDelay-v1.3.0.crx** 是签名扩展包，供允许侧载的浏览器或受管理的安装场景使用。Windows/macOS 普通 Chrome 对商店外 CRX 的安装有限制，无法安装时请使用 ZIP 加载方式。

`SHA256SUMS` 提供两个文件的 SHA-256 校验值。Release 的 CRX 和 ZIP 来自同一份打包内容，扩展 ID 保持一致。

### 已知验证边界

已在 macOS + Chrome 的 B 站真实直播完成短时观察。最终裁剪链路的端到端音画同步、完整 1～3 小时耐久及设备切换仍待验证；目标分辨率和帧率不等于实际播放表现。详见仓库中的 [TESTING.md](https://github.com/Aurxs/BilibiliLiveDelay/blob/v1.3.0/TESTING.md)。
