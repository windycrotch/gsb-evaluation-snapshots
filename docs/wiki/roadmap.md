# Roadmap

## Principio

Priorita alle idee tecniche che migliorano davvero il mix. La programmazione
segue questa mappa, non il contrario.

Il criterio e: prima spiegabilita e correggibilita del mix; poi automazione piu
intelligente; infine AI/modelli/export offline.

## Focus Tecnico

1. Timeline musicale interna.
2. Candidati di mix con punteggio e motivazioni.
3. Radio Edit Mix Mode realmente musicale.
4. Vocal risk su tutto il brano.
5. Phrase detection multi-risoluzione.
6. Cue-in professionale onset + spectral flux.
7. Planned transition condivisa da scoring, UI e player.

## Seconda Onda

- Tension profile.
- Chroma similarity e tension profile nello scoring.
- Crest factor, true peak e loudness range.
- Fade curve adattiva.
- Metadata tag scanning con `mutagen`.
- Cache analysis versionata.
- Debug view e test set musicale reale.
- Preset MIDI Hercules DJControl Inpulse 200.

## Backlog Strategico

- Miglioramento time-stretch con Rubber Band: richiede pipeline offline o shell desktop.
- Export set offline con ffmpeg: richiede timeline render separata dal player browser.
- Batch da cartella: richiede backend file-picker o app desktop.
- Downbeat con madmom: richiede ambiente Python <= 3.11.
- ONNX/embedding/key neurale dopo baseline DSP.
- Scorer ML dopo feedback umano e logging transizioni.
